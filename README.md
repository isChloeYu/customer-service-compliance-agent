# 售后客服回复合规质检 Agent

## 项目简介

针对电商售后客服对话的合规质检场景，用知识库检索法规条文，由大模型对模拟对话做初检，输出"合规 / 违规 / 待人工复核"，违规时写明类型和依据条文，最终判断由人做出。

本项目为方法验证项目，对话均为模拟数据，不接入任何业务系统，不构成法律意见。

## 知识库

法规依据（均来自官方发布渠道，仅依据全国性法律法规）：
- 《中华人民共和国消费者权益保护法》（2013年10月25日修正，2014年3月15日起施行）
- 《中华人民共和国消费者权益保护法实施条例》（2024年3月15日公布，2024年7月1日起施行）
- 《网络购买商品七日无理由退货暂行办法》（2017年1月6日公布，2020年10月23日修订）

## 主要结果

| 指标 | 第一轮（前30） | 第二轮（前30） | 第三轮（后10） |
|------|------|------|------|
| 结论类型准确率 | 30/30=100% | 30/30=100% | 10/10=100% |
| 违规召回率 | 15/15=100% | 15/15=100% | 5/5=100% |
| 误判率 | 0/10=0% | 0/10=0% | 0/4=0% |
| 法律法规引用率 | 6/20=30% | 20/20=100% | 6/6=100% |

测试集共40段，均为自编模拟数据；样本量小，结果不具统计意义。

## 分工

需求、规则设计、测试集与标准答案、错误归因、文档由本人完成；对话文本由 Claude 协助起草；Agent 搭建使用扣子（Coze）平台，模型为豆包·2.0·pro。

## 局限

- 对话为自编，措辞可能比真实场景更直白，评估结果可能偏乐观
- 标准答案由非法律专业人员依据法规文本确定，可能与专业判断有出入
- 知识库检索采用手工逐题方式，不支持批量自动化评测
- 样本量小（40段），结果不具统计意义
